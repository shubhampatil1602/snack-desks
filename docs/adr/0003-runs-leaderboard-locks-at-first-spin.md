# The Runs Leaderboard locks at the org's first spin of the day

The ranking comes from today's runs, since people run in the early morning. It is fixed at the org's first spin of the day and used for every window that day, so the Top Runner sits out all day as promised. It also stops anyone from running at lunch just to skip the evening window. A run uploaded after the lock doesn't count that day. This is deliberate, not a sync bug.
